# Storefront components

Shared presentation components used across public ecommerce pages:

- `StorefrontShell.tsx` — header, navigation, cart preview, breadcrumbs, and footer.
- `ProductCatalog.tsx` — reusable product grids, cards, sidebars, and catalog controls.
- `catalog-data.ts` — compatibility adapter for homepage catalog data.

Feature-specific behavior belongs in `frontend/features/storefront`.
